## Required route

1. Recruit Guardian/Mystic at the southern Tavern if desired, then enter the northern Nexus and inspect **The Gilded Vault** in Adventure. With TEST ACCESS off, an unearned Depth 5 clear must deny entry. A cleared/extracted Depth 5 or supported offline TEST ACCESS permits the implemented route only; it grants no clear or reward.
2. Enter the six-room layout. Note the visible seed, original return source and map. Walk the main loop and return path with both cameras. Verify broad doorway lanes, companion following, targeting and pet non-obstruction. Across repeat seeds, test both mirrored layouts and both hidden-leaf positions; record seeds for all four combinations.
3. Read the clue in the corridor. Its panel shows the actual three-rune order with only a Close/Return to exploring action. Try drag-off, repeated/multitouch, focus interruption and largest UI scale; it must not act as a city map, entry command or puzzle completion.
4. Walk onto SUN/MOON/STAR in the shown order. Test wrong order, standing still, stepping off/on and a menu opened while standing on a plate. Only a fresh physical player entry should count; companions/pets must not solve it. Camera switching must preserve sequence state. A solved puzzle remains solved.
5. Fight the original Corrupted Golem using actual sword/staff, block/dodge and companions. Verify its attack warning and death. Open the main treasury only after both puzzle and guardian requirements are met and attacks have finished. Search through the existing loot interface; test partial Take and Take All. No automatic reward should appear from clue reading or plate interaction alone.

## Optional branch and trap

2. Walk outside the marked circle, then test a normal dodge/block on another visit. One activation must not repeatedly damage or pay. Test a menu/focus pause during warning; returning must resume the same remaining warning rather than instantly catching up damage or rerolling the cache.
3. After warning/impact/recovery, search the optional cache. Repeated interaction, partial Take and a full inventory must preserve remaining contents without duplicate registration. Verify that skipping this whole room still permits ordinary main completion.
4. On a separate visit, approach return while the trap is active. Secure must explain the pending hazard; disclosed abandonment must remain available. Do not corrupt a personal save to simulate a fault.
