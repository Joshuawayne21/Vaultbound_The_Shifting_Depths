# Beastwilds Stage 5a — Android review checklist

For **`0.7.0-nexus5a` / Android export code 32**, which passed 15,526 native checks across 119 modes and 98 suites. Run this route using the reviewed build after publication. No physical Android result is claimed. Record device, Android/Godot versions, renderer, exact build/commit, graphics preset, resolution, UI scale, frame target and pass/fail/not-tested results.

## Install and migration

1. Back up the current phone profile and existing backups through supported device storage access. Keep the same application/user-data identity; a new source ZIP/folder does not migrate data between apps. Do not clear app data. After publication, use [GitHub main → Code → Download ZIP](https://github.com/Joshuawayne21/Vaultbound_The_Shifting_Depths) or the [main source ZIP](https://github.com/Joshuawayne21/Vaultbound_The_Shifting_Depths/archive/refs/heads/main.zip); no APK is supplied by this checklist. Preserve the same package/signing and application/user-data identity for an installed-app update. Import root `project.godot` with the compatible Godot 4.6.3 GDScript Android editor, verify `0.7.0-nexus5a`, and use **Run Project** in landscape.
2. Record secured DM, important item UIDs, upgrades/locks/favorites, active weapons, earned depths, recruited companions, pet ownership/aliases/variants, home ID/theme and display selections. On a backed-up progressed profile, confirm migration preserves them and existing services. Where storage access allows, verify the original pre-v12 migration backup remains; do not edit real saves to inject faults.
3. On a fresh/disposable profile with TEST ACCESS off, approach Beastwilds inside the north Nexus. It must be inspectable but locked until Depth 2 is actually cleared and extracted. Unlocking Depth 2 alone is insufficient. On a separate eligible profile, enter normally. Test the existing offline TEST ACCESS bypass separately; it must not record a permanent clear or grant findings.

## Discovery route

4. Recruit Guardian/Mystic and select an owned cosmetic pet before entry. Verify one player, two companions and one active pet arrive on supported ground. The forest must be its own scene with **THE BEASTWILDS**, `0 / 3 DISCOVERIES` and the correct map; no fake floor/boss result should appear.
5. Walk the full circular route in third-person and isometric views, toggling while moving near the giant tree, water, mushrooms and ruins. Followers should use the route without oscillation or recovery teleports. Inspect the central tree/camera envelopes and all source approaches for clipping, foliage obstruction and unclear interaction prompts.
6. Use the actual interaction control at the Lantern Glade trail, Mooncap egg and Crystalwater spirit. Each required source should progress the objective exactly once, to `3 / 3`. Repeat taps, hold, drag off, change camera and reopen displays; findings/DM must not repeat. Approach from behind nearby scenery to check through-wall interaction is denied.
7. Search the optional Old Explorer's Terrace cache and inspect the existing bag/pet-findings view. Rewards remain unsecured: configured egg 4–8 DM, rescue 6–10 DM, optional cache 8–12 DM plus 2–4 root fiber, alongside existing egg/rescue Spiritweaving ingredients/memories. No owned pet is created by the interaction, and optional forage does not raise the required count above three.
8. With all required finds, review **SECURE & RETURN** at the southern spring. Cancel once, then confirm. Verify return to the Nexus, one results screen and the expected secured additions after restart. Dungeon clears/unlocks/XP, companion XP, merchant rotation, Rootwarden counters and existing secured pet achievements must not increase merely from Beastwilds completion. Visit the original Sanctuary Spiritweaving service afterward; recipe eligibility still uses the actual existing ingredients/milestones.
