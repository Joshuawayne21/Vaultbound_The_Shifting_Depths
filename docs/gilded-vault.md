# The Gilded Vault — first treasure expedition

**Stage 5c: `0.7.0-nexus5c` / Android code 34 / profile 14 / activity 3 passed 24,722 assertions across the approved 157-mode regression matrix (131 test scripts), including eighteen independent restart readers, plus import, 52 strict loads and 120 startup frames.** This is verified source; remote publication is verified separately. No rendered/device acceptance, APK or phone installation is claimed. See [validation](nexus-stage5c-validation.md), [Android route](nexus-stage5c-android.md) and [ordered plan](nexus-realms-plan.md). The [earlier data foundation](nexus-gilded-foundation-validation.md) remains historical evidence.

The playable slice reuses six original native room modules, the existing human/Guardian/Mystic party, Corrupted Golem, cameras, inventory, pooled Search/Take UI and secure-return flow. It adds one physical rune puzzle, a main treasury and an optional hidden trapped cache. It is a finite local treasure expedition, not a new biome, mimic system or online activity.

## Entry and room route

After release, use Sanctuary's north Nexus entrance, then **The Gilded Vault** in the Adventure gallery. Normal entry requires a verified **Depth 5 clear and successful extraction**; the existing offline TEST ACCESS option can bypass this requirement without granting the clear. Inspection alone must not write progression. The shared gate and return must retain existing party, pets and saved home state.

Original room materials receive bounded ivory/amber accents and rune/treasury source models; these are native prototype visuals, not new production art.

## Physical rune puzzle and guardian

Read the clue tablet to see the issued SUN/MOON/STAR order, then close it and step onto the original plates in that order. Only the living player counts; companions and cosmetic pets cannot solve or reset it. Leave a plate's footprint before re-entering. Standing still or reopening a menu must not create an extra step. Wrong order harmlessly resets sequence progress; a completed sequence stays solved during the visit. The clue itself is informational and does not award a proof or reward.

The native Corrupted Golem retains its existing combat and telegraphs. Main treasury access requires both the solved puzzle and the original guardian's genuine death, with any attack delivery finished. A freed, replaced or living enemy cannot count. The puzzle and guardian can be completed in either order; neither closes the return route. No new boss, special boss trophy, mask or altered combat family is added.

## Treasuries and optional trap

Interact with the main treasury after both required proofs. It registers one original searchable cache; use **Search**, **Take** or **Take All** to move selected contents into the existing unsecured bag. Capacity rejection leaves the remainder available. Registration, partial collection and reopening cannot reroll its contents. Initial definition tuning uses 45–70 DM, iron ore and one existing collectible valuable; these values are pending gameplay balance review.

The optional reveal source opens one physical barrier into the hidden hollow. Its first trapped-treasury interaction starts a visible **2.2-second circular warning**, followed by one existing-rules impact and recovery. It must leave two real escape directions. Walk or dodge outside the marked area; normal block/dodge rules remain. An open menu or focus interruption pauses the same cast without resetting it or catching up damage. The warning is a one-shot encounter, not a repeatable reward source.

After the native trap completes, search the optional treasury for its existing DM/material/consumable rewards. Initial tuning is 15–25 DM, root fiber and a possible Mooncap Tonic. Ignoring the entire hidden room never blocks main completion. An active trap or damage dispatch temporarily prevents securing rewards; the return card explains the wait and retains disclosed abandonment.

## Secure, abandon and persistence

The three required proofs are **puzzle solved, guardian defeated and main treasury registered**. Once all three are valid and damage has drained, the original return source offers **SECURE & RETURN** to the Nexus. Only actually taken rewards are saved; the review warns about unclaimed contents. Before completion, **ABANDON & RETURN** loses only this visit's unsecured loot. Closing the card continues exploration. Failed saves must remain retryable; after a saved result, failed travel must retry only the return rather than granting a second result.

Profile 14/activity namespace 3 adds one Gilded record while retaining home namespace 3 and the exact Beast/Echoes records, tickets, serials, owned possessions and currency. Records cover entries, completions, deaths, abandonments, completed main/hidden discoveries, secured DM, best complete time and last completed serial. Only a successfully secured completion increments treasure discovery counts. All three activities share one monotonic serial and at most one open ticket; interrupted visits are retired against their original activity.

Loading does not write. The first valid migration write preserves exact prior bytes in `.pre-v14.bak`, retaining older backups. Unknown future/incompatible data stays protected; a missing current namespace must not become empty defaults. Equipment UIDs/upgrades, pets, companions, depth clears, trophies and home displays must survive unchanged. Runtime puzzle/trap/loot progress does not resume after process termination.

No character/companion XP, Rootbound clear, merchant rotation, pet grant, new trophy, mask, seal or mastery is awarded. Masks remain explicitly user-deferred. Gilded is the fifth major local route; Titan's Gate, Shattered Rift, Guild Conquest, Chaos Gate and Forbidden Gate remain unavailable.
